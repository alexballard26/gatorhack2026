# Gator Hack V — Rules & Requirements

Verified 2026-10-23 against the official Devpost pages (gatorhack2026.devpost.com, /rules) and ufgatorhack.com (FAQ, prizes, schedule). Organizers may change rules; changes are announced on Discord and Devpost.

## Hard rules (break these = disqualified / ineligible)
- **Fresh code only.** All project code written between **Fri Oct 23, 5:00 PM ET** and **Sun Oct 25, 5:00 PM ET**. Open-source libraries, frameworks and public APIs are fine; no pre-written project code. → Nothing in this repo before 5 PM Friday counts as project code (these planning docs are not code).
- **Team of 2–5.** Solo submissions are not eligible. Every member must be registered.
- **One project per team.** Submitted on Devpost.
- **No late submissions.** Deadline Sun Oct 25, 5:00 PM ET. Leave buffer.
- **Finals attendance.** If you're a top-10 finalist, at least one member must be physically at Reitz Union **Mon Oct 26, 10:15 AM**, or the team can't win.
- **MLH Code of Conduct** applies (mlh.io/code-of-conduct).
- In person only; 18+; currently enrolled students.

## AI coding tools
No rule found on Devpost or the official site restricting AI assistants (Claude, Copilot, etc.). The schedule even includes a "How to Use Claude" workshop (Sun 1:00 PM). Low risk, but **confirm with an organizer at check-in** to be safe.

## Devpost submission checklist (due Sun 5:00 PM ET)
- [ ] Project title + short description (what it does, how it was built)
- [ ] Link to a **public** code repository (GitHub)
- [ ] Demo video (**3 min max**) or slides — honest WIP demo is acceptable
- [ ] Full team roster (2–5, all registered)
- [ ] Tracks / sponsor challenges selected

## Judging
- Round 1: offline, UF grad students, after submissions close → top 10 finalists announced before Monday morning.
- Round 2: live on-stage pitch, Mon Oct 26, 10:15–11:15 AM (≈ 10 teams in 60 min → plan for ~3–5 min pitch). Awards 12:15 PM.
- **Devpost criteria:** Impact · Technical Execution (incl. what was accomplished during the hack) · Design & Usability · Presentation & Demo.
- Official site also lists **Novelty** — treat it as a fifth criterion.
- Round 1 is judged from the Devpost page alone → the **video and write-up are what gets us into the top 10.**
